      Model library

      Every model is ordinary primitives with an editable animation clip — drop one in, then restyle, re-shape or re-time it like anything else in the scene.

      AnimForge — quick guide

      Build

      • Click a primitive to drop it in the scene — or open the Model library (L) for ready-made animated humans, animals and props.
      • Swap any object to a different primitive with the Convert to row, and bend it with Taper / Twist.
      • Library models drop in with their own clip — tick Add to current clip to merge a model's animation into the clip you are already working on.
      • A model is a group you can reshape: select the whole figure and drag the gizmo, click a part to recolour / convert / taper it, or Split it into loose objects.
      • Select an object, then drag the gizmo (or use W / E / R for move / rotate / scale).
      • Tweak size, colour and finish in the inspector.

      Animate

      • Scrub the timeline, then hit ◆ Key (or K) to record a pose.
      • Move the playhead and change the transform — auto-key records it.
      • Drag diamonds on the timeline to retime. Double-click a diamond to cycle easing.
      • Stack several clips for different actions.

      Shortcuts

      • Space play / pause
      • K insert key   Del delete key / object
      • WER move / rotate / scale
      • F frame selection   D duplicate
      • ← → step frame   Home go to start
      • Ctrl/⌘ Z undo   Ctrl/⌘ ⇧ Z redo
      • Ctrl/⌘ S save project   L model library

      Export

      • Export GLB writes a binary glTF with every clip baked as a glTF animation — drop it into Blender, Unity, Godot, three.js or any AR viewer.
      • Save writes an editable .json project you can reopen later.
